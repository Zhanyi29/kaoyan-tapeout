>
> 🚀 **当前开源发布模块**：专为全国硕士研究生统一招生考试（考研数学二、考研英语一/英语二）打造的高精度专业级智能阅卷、逐题精批与备考复盘 Agent 技能包（Skills）。
> 遵循真实考研阅卷评分细则、采分点矩阵与命题逻辑，彻底告别普通 AI 评语空泛、标准不一、直接判零分或脑补学生答案的问题。

## ✨ 核心特性

### 1. 📐 考研数学二智能阅卷 (`kaoyan-math2-grader`)
- **真实阅卷与过程分保护**：
  - 严谨区分「单纯计算错误」与「核心方法错误」：思路正确但在某一步算错时，前面正确步骤正常给分，后续推导合理处按阅卷细则给予过程分，严禁直接判 0 分。
  - 多解保护：考生解题方法与标准答案不同（如换元法、微分方程特解法不同），只要逻辑严密自洽均给予满分。
  - 严禁脑补推导，只依据答题卡实际书写内容客观判定。
- **三大场景智能分流**：
  - **整卷解答题批改**：启动门控识别 → 逐题采分点拆解与错误定位 → 解答题总得分统计 → 七维复盘报告（失分结构、知识点短板、TOP 3 根因、提分策略） → 自动生成带日期错题本。
  - **单题深度精批**：单题诊断、逐步分析、扣分点矩阵与变式重做建议。
  - **阶段复盘与错题重构**：自动汇总历史错题，生成题答彻底分离的《阶段纯净重做卷》与《全卷错题重构攻坚总汇》。
- **强制题答分离排版**：
  - 归档错题集时，严格保证「所有题目在前，所有解析在后」，方便二次打印或无干扰重做。
  - 文件命名强制携带完成日期（例如：`2027张宇八套卷_卷一_2026-09-20.md`）。

---

### 2. 📝 考研英语主观题智能精批 (`kaoyan-english-grader`)
- **完整覆盖考研英语六大主观题型**：
  - **英语一大作文**（图画作文，20分）
  - **英语一小作文**（应用文书信/通知，10分）
  - **英语一翻译**（5个长难句拆分，10分，按意群拆分并严格执行错别字扣分细则）
  - **英语二大作文**（图表作文，15分，严格区分动态/静态图表与百分比/百分点）
  - **英语二小作文**（应用文，10分）
  - **英语二翻译**（段落英译汉，15分，意群采分矩阵）
- **手写识别安全底线**：
  - 手写拍照或答题卡照片输入时，先忠实完整转录学生原文（保留原拼写与语法，不暗中纠错）。
  - 字迹模糊处单独标注提示，绝不将 OCR 识别错误嫁祸为学生语法扣分。
- **卷面格式与字数 Checklist 核验**：
  - 书信称呼标点、首段缩进与顶格一致性、落款签名格式防幻觉核查。
  - 纯正文单词数精准统计，核验考场安全词数区间。
- **两级诊断体系**：
  - 严格区分 **【必须修改】**（真实语法硬伤、拼写、逻辑断层）与 **【可选优化】**（地道表达、句式升级）。
  - 保护简单基础表达：正确但简单的句式不扣分，不唯生僻词长难句论。
- **双重归档与闪卡沉淀**：
  - 单篇生成完整批改复盘报告（含修改后范文并加粗关键替换）。
  - 自动将考场高频弱项、地道表达同步追加至全局 `个人考场高频弱项与闪卡句式库.md`，可一键导入 Anki 随时复习。

## 🚀 快速上手与安装配置

### 方式一：在 Google Antigravity 中使用
1. 将本仓库的 `.agents/skills/` 文件夹复制到你的工作区根目录下，或放入 Antigravity 全局 Skills 目录：
   ```bash
   # 项目级别（推荐）
   your-project/
   └── .agents/
       └── skills/
           ├── kaoyan-math2-grader/
           └── kaoyan-english-grader/
   ```
2. 启动 Antigravity，Agent 将自动发现并注册两个 Skills。

### 方式二：在 Claude Code / Cursor / Codex 等 Agent 中使用
1. 将技能文档引入到系统 Prompt 或作为 Project Rules / Agent Skills。
2. 核心主入口文件为各技能目录下的 `SKILL.md`，详细评分标准与输出模板位于各子目录下的 `references/` 中。
