遵循真实阅卷评分细则、采分点矩阵与命题逻辑，提供严谨的过程分判定、错误归因诊断与题答分离错题闭环。

## ✨ 核心特性

### 1. 📐 主观解答题智能阅卷 (`kaoyan-math2-grader`)
- **真实阅卷与过程分保护**：
  - 严谨区分「单纯计算错误」与「核心方法错误」：思路正确但在某一步算错时，前面正确步骤正常给分，后续推导合理处按细则给予过程分，严禁直接判 0 分。
  - 多解保护：解题方法与标准答案不同时，只要推导合理、逻辑自洽均正常给分。
  - 严禁主观脑补推导，只依据答题卡实际书写内容客观判定。
- **三大场景智能分流**：
  - **整卷解答题批改**：材料核验 → 逐题采分点拆解与错误定位 → 解答题得分统计 → 多维复盘报告（失分结构、知识点短板、TOP 3 根因、提分建议） → 自动生成带日期错题本。
  - **单题深度精批**：单题诊断、逐步分析、扣分点矩阵与变式重做建议。
  - **阶段复盘与错题重构**：自动汇总历史错题，生成题答彻底分离的《阶段纯净重做卷》与《错题重构攻坚总汇》。
- **强制题答分离排版**：
  - 归档错题集时，严格保证「所有题目在前，所有解析在后」，方便二次打印或无干扰重做。
  - 文件命名规范携带完成日期。

---

### 2. 📝 写作与翻译智能精批 (`kaoyan-english-grader`)
- **完整覆盖考场主观题型**：
  - 各类图画、图表作文定档精批；
  - 各类应用文（书信/通知等）格式与内容核验；
  - 英译汉篇章与划线长难句采分矩阵评分。
- **手写识别安全底线**：
  - 手写拍照或答题卡照片输入时，先忠实完整转录学生原文（保留原拼写与语法，不暗中纠错）。
  - 字迹模糊处单独标注提示，绝不将 OCR 识别错误判定为学生作答扣分。
- **卷面格式与字数 Checklist 核验**：
  - 称呼标点、首段缩进与顶格一致性、落款签名格式防幻觉核查。
  - 纯正文单词数精准统计，核验考场安全词数区间。
- **两级诊断体系**：
  - 严格区分 **【必须修改】**（真实语法硬伤、拼写、逻辑断层）与 **【可选优化】**（地道表达、句式升级）。
  - 保护基础表达：正确但简单的句式不扣分，不唯生僻词长难句论。
- **双重归档与闪卡沉淀**：
  - 单篇生成完整批改复盘报告（含修改后范文并加粗关键替换）。
  - 自动将考场高频弱项、地道表达同步追加至全局闪卡库，便于随时复习。

## 🚀 快速上手与安装配置

### 方式一：在 Google Antigravity 中使用
1. 将本仓库的 `.agents/skills/` 文件夹复制到你的工作区根目录下，或放入 Antigravity 全局 Skills 目录：
   ```bash
   your-project/
   └── .agents/
       └── skills/
           ├── kaoyan-math2-grader/
           └── kaoyan-english-grader/
   ```
2. 启动 Antigravity，Agent 将自动发现并注册这两个 Skills。

### 方式二：在 Claude Code / Cursor / Codex 等 Agent 中使用
1. 将技能文档引入到系统 Prompt 或作为 Project Rules / Agent Skills。
2. 核心主入口文件为各技能目录下的 `SKILL.md`，详细评分标准与输出模板位于各子目录下的 `references/` 中。
