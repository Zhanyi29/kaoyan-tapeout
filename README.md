面向考研主观题的高精度智能阅卷、逐题精批与备考复盘 Agent 技能库（Skills）。

遵循真实阅卷评分细则、采分点矩阵与命题逻辑，提供严谨的过程分判定、错误归因诊断与题答分离错题闭环。

## ✨ 核心特性

### 1. 📐 主观解答题智能阅卷 (`kaoyan-math2-grader`)
- **关键答案显式核验与防识别误判底线**：
  - 每道题必先在独立表格中显式提取呈现**考生实际写出的关键中间答案与最终结论**（如特征根、驻点/极值、齐次通解、非齐次特解、定积分值等），供考生直观核对 AI 是否看错手写数字或符号，彻底杜绝识图误差导致的误判。
  - 字迹模糊或修改处打上【字迹存疑待核对】标记，以考生实际笔迹为准。
- **解题过程深度展开与考场 30 秒验算绝招**：
  - 严禁一笔带过的粗略点评，逐段还原考生的推导演算轨迹；
  - 深度剖析算理、公式选用、换元代入、变形消元及逻辑自洽性，精确定位失分细节；
  - 每道题后必须输出 **【考场 30 秒极速自检法】**（如：特征值与迹 $\sum \lambda_i = \mathrm{tr}(A)$ 验算、微分方程代回原式、奇偶对称性判号等），从“被动纠错”升级为“主动授渔”。
- **高频运算扣分锚定标尺与证明题阅卷专章**：
  - 对标真实考研阅卷组尺度，严格规范未定式极限滥用等价无穷小、变限积分链式求导、微分方程特解设错等高频运算扣分标尺；
  - 增设证明题专章：分步考核定理前提条件显式验证分、辅助函数构造破局分，严查“循环论证”倒推硬伤。
- **真实阅卷与过程分保护**：
  - 严谨区分「单纯计算错误」与「核心方法错误」：思路正确但在某一步算错时，前面正确步骤正常给分，后续推导合理处按细则给予过程分，严禁直接判 0 分。
  - 多解保护：解题方法与标准答案不同时，只要推导合理、逻辑自洽均正常给分。
- **三大场景智能分流与题答分离归档**：
  - 支持整卷解答题批改、单题深度精批与阶段错题重构；
  - 错题集强制实现“所有题目在前，所有解析在后”的纯净重做排版，文件名规范携带完成日期。

### 2. 📝 写作与翻译智能精批 (`kaoyan-english-grader`)
- **“反假大空模板”与主题实质咬合诊断**：
  - 遵循“骨架用模板，血肉精准定制”法则；
  - 严查通篇无实体信息的空洞套话，核验大作文首段实体名词与论证段考研核心实词密度，对假大空模板发出预警并示范如何注入题目血肉，防止考场严重降档。
- **小作文语域与语气得体性核验 (Tone & Register Check)**：
  - 严格核验正式 (Formal)、半正式 (Semi-formal) 与熟人 (Informal) 语域；
  - 严禁写给教授/机构时使用轻佻俚语或生硬命令句（如 `You must...`），避免隐形语用扣分。
- **英译汉长难句三层采分透视法**：
  - ① 骨架主干层（主谓宾动作与否定重心，占 50% 分值）；
  - ② 修饰与指代层（代词还原、长定语拆译、被动转主动，占 30% 分值）；
  - ③ 熟词生义与引申层（学术高频词语境引申，占 20% 分值）。
- **逐句精批行内精准标记与扣分权重标签**：
  - 在原句中行内锁定微观病灶（如 `[主谓不一致: were → was]`）；
  - 明确标注【必须修改（考场硬伤扣 0.5~1 分）】与【可选优化（提升地道度，不扣分）】，让考生清楚每一分的得失。
- **手写识别安全底线与双重归档闭环**：
  - 忠实转录学生手写原文，不将识图误差当成语法扣分；
  - 生成单篇精批报告并自动同步更新至全局个人闪卡库，便于随时导入 Anki 复习。

## 🚀 快速上手与安装配置

### 方式一：在 Google Antigravity 中使用
1. 将本仓库的 `.agents/skills/` 文件夹复制到你的工作区根目录下，或放入 Antigravity 全局 Skills 目录：
   ```bash
   your-project/
   └── .agents/
       └── skills/
           ├── kaoyan-math2-grader/
           └── kaoyan-english-grader/
   ```
2. 启动 Antigravity，Agent 将自动发现并注册这两个 Skills。

### 方式二：在 Claude Code / Cursor / Codex 等 Agent 中使用
1. 将技能文档引入到系统 Prompt 或作为 Project Rules / Agent Skills。
2. 核心主入口文件为各技能目录下的 `SKILL.md`，详细评分标准与输出模板位于各子目录下的 `references/` 中。
