# 信号与系统专业课评分细则（逐题批改前必读）

## 一、评分依据优先级

批改时按以下优先级采用评分依据（从高到低）：

1. **目标高校官方评分标准与参考答案**；
2. **工作区本地专业课真题解析库**（`信号与系统/03_真题与解析/` 下历年 PDF 与 markdown 试卷）；
3. **考生提供的标准答案与评分说明**；
4. **经典教材标准**：
   - 连续与离散经典：Alan V. Oppenheim《Signals and Systems》（奥本海姆第 2 版）；
   - 国内权威教材：郑君里《信号与系统》（第 3 版）、吴大正《信号与线性系统分析》（第 5 版）；
5. **AI 自行推导的严格数学物理证明**（必须明确声明）。

---

## 二、无标准答题卡作答识别与容错准则

由于专业课考生大多在空白 A4 纸、白纸、横线纸上作答，必须遵循以下识别与判定底线：

1. **题号动态映射与顺序容错**：
   - 考生的作答顺序可能打乱（如先做计算大题，再做填空题），或写在不同页面的边角处；
   - AI 必须全局扫描作答图片，根据手写标记（如“二、12”、“第26题”、“计算(2)”）或核心特征算式（如识别出微分方程、状态矩阵）自动锚定题目；
   - 若考生完全未标明题号且上下文存在歧义，标注【题号存疑，依据算式特征判定为第 X 题，请考生确认】。
2. **字迹模糊与防识图误判底线**：
   - 手写数学物理表达式常出现上下标、正负号、时域连续 $t$ 与离散 $n$ 混淆、$\omega$ 与 $w$ 混淆、积分限断线等歧义；
   - 歧义处**必须标明【字迹存疑待核对】**，写明“此处按 X 识别，若原作为 Y 请指出”；
   - 只要考生后续指出识别有误，必须无条件以考生澄清的实际作答为准重判。
3. **关键答案显式提取核验（防识别误差）**：
   - 每道主观题批改前，必须在专设表格中显式列出 AI 识别到的考生关键结果（系统函数、冲激响应、收敛域、状态方程、终值等），供考生第一眼比对。

## 三、客观题批改规则（填空直接识别，选择识别或列出答案）

### 1. 填空题批改规则（直接识别与比对）
- **直接识别作答**：直接从作答切图中识别填空题手写最终答案；
- **全对或全错原则**：对标考研官方阅卷，填空题只有对（给满分，通常 3~5 分）和错（0 分），无过程分；
- **数学与物理等价形式判定**：
  - 若考生作答与标准答案形式略有不同但数学本质完全等价（如：分母未有理化但数值等价、常数因子提前或合并、三角函数展开式同解），给予该题满分；
  - 若漏掉负号、遗漏冲激因子 $\delta$、或漏掉单位阶跃 $u(t)/u[n]$ 导致因果区间缺失，判 0 分；
- **字迹存疑**：字迹模糊时标注【字迹存疑待核对】，提示考生核验，若考生确认真实作答正确，修正为满分。

### 2. 选择题批改规则（能识别则识别，识别不了直接列出答案）
- **能识别则识别并判分**：
  - 若考生上传了选择题手写选项记录（如 `1.A 2.C ...`）或试卷勾选题号，AI 直接识别选项，与官方标准答案比对（对给该题满分 2~3 分，错给 0 分）；
- **识别不了直接列出标准答案清单（防卡壳、供比对）**：
  - 若考生未上传选择题作答部分或标记过于潦草模糊无法确认，**坚决不阻塞批改流程，也不凭空猜测**；
  - **直接在客观题批改表格中完整列出选择题官方标准答案清单**；
  - 明确提示考生根据标准答案自查核对，并在对话中告知做错的题号；
  - 收到考生核对反馈后，即时补录得分并同步更新客观题小计及全卷总成绩。

## 四、波形图与频谱图专项评分原则

信号与系统常考画图题（时域波形图、卷积结果波形图、频谱幅度/相位谱、零极点分布图、抽取序列波形）：

1. **坐标轴与物理量标度（占 20% 分值）**：
   - 坐标横轴自变量（$t, n, \omega, \Omega$）与纵轴因变量（$x(t), x[n], |X(j\omega)|, \arg X(j\omega)$）标度清晰；
   - 漏标横纵坐标物理量符号扣 1 分。
2. **关键拐点与关键幅值（核心得分点，占 50%~60% 分值）**：
   - 折线波形的起始点、转折点坐标，平顶宽度与周期；
   - 离散序列样本线（针状图）的非零取值点与幅值高度；
   - 关键拐点坐标与幅值正确即给大部分分，不苛求美术级线条平滑度。
3. **冲激函数 $\delta$ 特殊标度规范（采分点 1~2 分）**：
   - 画连续冲激 $\delta(t)$ 时，必须使用**带箭头的垂直线段**，并在箭头旁用括号标出**冲激强度/面积**（例如 `(2)`、`(-1)`）；
   - 漏标冲激箭头强度括号扣 1 分；冲激方向与正负号画反该点判错。
4. **周期性与延拓说明（采分点 1~2 分）**：
   - 离散时间傅里叶变换（DTFT）频谱必须体现出以 $2\pi$ 为周期的周期性；
   - 抽取/插值序列波形必须注明全域定义或画出两个以上完整周期。

## 五、主观大计算题核心采分点与过程分保护

### 1. 时域分析（卷积积分与微分/差分方程）
- **时域图解卷积 / 解析卷积**：
  - **分段讨论区间划分（核心采分点，占 40% 分值）**：写出不同重叠区间（如 $t < 0$、$0 \le t < 1$、$1 \le t < 2$、$t \ge 2$）即给区间分；
  - **积分表达式与计算（30% 分值）**：被积函数与积分限代入正确给分；
  - **最终分段表达式汇总（30% 分值）**：若中间某段积分因符号算错，仅扣该段计算分，其余正确区间全额给分。
- **经典法与全响应分解**：
  - 齐次解形式与特征根（给 2~3 分）；
  - 特解设法与待定系数（给 3~4 分；特解设错扣除特解分，齐次解分保留）；
  - 初始状态代入确定待定常数（给 2~3 分）；
  - 零输入响应 $y_{zi}(t)$ 与零状态响应 $y_{zs}(t)$ 分解独立采分。

### 2. 变换域与收敛域 ROC 铁律（严谨性审查）
- **拉普拉斯变换 $X(s)$ 与 Z 变换 $X(z)$ 的收敛域 ROC**：
  - **写出变换式必须附带收敛域 ROC**！式子完全正确但漏写 ROC 者，考场扣 1~2 分；
  - **由因果性/稳定性选择收敛域**：因果系统极点必须在 ROC 内部（右边序列）；稳定系统 ROC 必须包含虚轴（连续 $s$ 域）或单位圆（离散 $z$ 域 $|z|=1$）；若选错 ROC 导致求出的逆变换因果性完全反转，该逆变换步骤扣 3~5 分。
- **部分分式展开法与留数计算**：
  - 极点展开形式写对（给 2~3 分）；
  - 留数系数算错属于单纯计算错误，扣除对应项分值，后继查表求逆变换方法正确者保留过程分。

### 3. 系统函数 $H(s)/H(z)$ 与系统特性判定
- 传递函数求取：S域电路阻抗模型或时域方程变换（给 3~4 分）；
- 极零点列写（给 2 分）；
- 频响特性与 Bode 图（幅频、相频渐近线）（给 3~4 分）；
- 因果性与稳定性判定依据（必须写出极点分布与 ROC 关系，光写结论无依据扣 1 分）。

### 4. 状态空间分析法（状态方程与输出方程）
- **列写状态方程与输出方程**：
  - 状态变量选取与节点/网孔方程列写（给 3~4 分）；
  - 整理为标准矩阵形式 $\dot{x} = Ax + Bu, y = Cx + Du$ 或 $x[n+1] = Ax[n] + Bv[n]$（矩阵 $A, B, C, D$ 提取正确给 3~4 分）；
- **转移函数求取**：$H(s) = C(sI - A)^{-1}B + D$（公式正确给 2 分，矩阵求逆与乘法合理给过程分）。

### 5. 抽样定理与信号滤波
- 奈奎斯特抽样频率 $\omega_s \ge 2\omega_m$ 判定（给 2 分）；
- 抽样后频谱 $X_s(j\omega) = \frac{1}{T}\sum X(j(\omega - k\omega_s))$（遗漏幅值比例因子 $\frac{1}{T}$ 或漏乘 $2\pi$ 扣 1~2 分）；
- 低通滤波器恢复与截止频率设定（给 2~3 分）。

## 六、错误分类（A–F）

对考生的每一个主要失分点，归入以下标准分类：

- **A. 概念错误**：混淆连续与离散性质；混淆收敛域 ROC；误解因果性与稳定性充要条件；频域卷积定理误用；
- **B. 方法错误**：解题方向选错；不会使用 S 域等效模型；不会用梅森公式；逆变换方法选错；
- **C. 推导错误**：分段卷积积分限搞错；特征根代数变形错误；矩阵求逆代数逻辑断层；
- **D. 计算错误**：加减乘除计算笔误；符号正负号弄反；留数系数算错；三角函数变换遗漏常数；
- **E. 审题错误**：看错输入信号波形；漏做某一问；看错初始条件（如零状态误当全响应）；
- **F. 书写或表达问题**：波形图漏标坐标轴与冲激强度；漏写收敛域 ROC；表达式未化简或跳步严重。
