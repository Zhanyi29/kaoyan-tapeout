# 第一部分：整体表现与专业素养分析

从专业课《信号与系统》核心素养维度分析考生表现：

- **时域分析素养**：卷积积分/卷积和区间分段是否清晰，时不变性与因果性判定是否扎实。
- **频域物理直觉**：对连续傅里叶（FT/FS）与离散傅里叶（DTFT/DFS）的对称性、周期性、抽样混叠与滤波机制是否有直观把握。
- **复频域与极零点分析能力**：拉氏变换与 Z 变换收敛域 ROC 判定是否敏锐，能否熟练利用极零点几何分布分析系统频率响应。
- **离散时间系统处理能力**：是否存在“重连续、轻离散”的偏科现象，差分方程与离散抽取是否熟练。
- **状态空间与电路建模能力**：系统状态方程矩阵列写与 S 域电路等效阻抗模型的熟练度。

# 第三部分：核心知识模块复盘

按《信号与系统》大纲核心模块标记掌握情况：
- 🟢 掌握较好
- 🟡 基本掌握，但偶有疏漏
- 🟠 存在明显漏洞
- 🔴 需要重点攻坚

### 1. 时域分析
- 连续与离散信号基本运算（平移、反褶、尺度变换、微分积分）
- 冲激函数 $\delta(t)$ 与阶跃函数 $u(t)$ 奇异性质
- 连续卷积积分与离散卷积和（解析法与图解法）
- 微分方程与差分方程时域经典解法（零输入与零状态）

### 2. 连续时间频域分析
- 周期信号傅里叶级数（三角形式、指数形式、功率谱与帕塞瓦尔定理）
- 连续时间傅里叶变换（性质、对称性、能量谱）
- LTI 系统的频域分析（频率响应 $H(j\omega)$、无失真传输条件、理想低通滤波器）
- 连续抽样定理（时域抽样、频域抽样、混叠与重建）

### 3. 连续时间复频域分析（Laplace 变换）
- 拉氏变换定义与收敛域 ROC
- 拉氏反变换（部分分式展开法、留数法）
- S 域系统函数 $H(s)$、极零点分布与因果稳定性判定
- 电路 S 域阻抗模型与状态响应分析

### 4. 离散时间频域与 Z 域分析
- 离散时间傅里叶变换（DTFT）及其性质
- Z 变换定义与收敛域 ROC
- 逆 Z 变换求解与差分方程 Z 域求解
- 离散系统函数 $H(z)$、频率响应与单位圆稳定性判定

### 5. 系统状态变量分析法
- 连续与离散系统的状态方程与输出方程建立（由微分/差分方程、信号流图）
- 状态转移矩阵求解与转移函数计算
