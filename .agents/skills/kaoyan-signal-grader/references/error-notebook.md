# 信号与系统错题集整理与归档规范（批改与复盘后必读）

## 一、整理目标与时机

每套《信号与系统》专业课试卷批改和整卷复盘输出完成后，**必须自动执行错题归档**：
将本套试卷中所有产生失分的题目（包含判错的选择题、填空题，以及大题扣分题），整理为一个独立的 Markdown 文件，存放在工作区根目录的 `错题/` 文件夹下。

- **目标存储路径与命名规范（强制包含完成日期）**：
  - **高校历年真题**：`错题/真题/<年份与院校代码名称>_<完成日期>.md`
    - 例如：`错题/真题/2023年华中科技大学824真题_2026-10-18.md`
    - 例如：`错题/真题/2022年北京邮电大学801真题_2026-10-20.md`
  - **模拟卷与月考测验**：`错题/模拟卷/<辅导机构或名校名称>/<卷名>_<完成日期>.md`
    - 例如：`错题/模拟卷/月考模拟/2027年信号月考09卷_2026-10-22.md`
  - **阶段复习汇总卷**：`错题/阶段复习/<复习主题与阶段>_<完成日期>.md`
- **命名铁律**：文件名中**必须保留清晰院校试卷名与完成日期**（格式：`_YYYY-MM-DD.md`），严禁省略日期。

---

## 二、核心排版铁律（最高优先级）

> [!IMPORTANT]
> **「题目集中在前」与「答案集中在后」彻底分离，严禁“一题一解”穿插排版！**
> 
> - **前半部分（题目汇总篇）**：所有错题的完整题干必须集中放在一起，**绝对不能**在题目下方紧跟答案、解析或错因提示。其目的是作为一份纯净的“重做卷”，方便考生闭卷二次练习、打印或在草稿纸上重做。
> - **后半部分（答案解析篇）**：所有错题的官方标准答案、详细推导、给分步骤、考场错因深度诊断与考点提炼集中放在后面。

---

## 四、执行要点

1. **官方解法优先**：答案与解析必须严格以目标院校官方解析为主，优先取自工作区本地资料库（`信号与系统/` 目录）；
2. **波形描述严谨**：波形题必须写出关键坐标拐点（$t_1, t_2$）、幅值和冲激强度，公式排版使用规范 LaTeX；
3. **完成后即时汇报**：文件写入完毕后，在向用户汇报的对话中提供指向该文件的可点击链接，并简要概括错题结构。
