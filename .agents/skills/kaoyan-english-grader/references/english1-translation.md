# 英语一 翻译批改规范（5 个划线长难句，满分 10 分，标准版）

## 一、真实考场评分尺度与评分规则（严格对标原版）

考研英语一划线长难句翻译全国历年平均分仅在 **4.5 ~ 5.5 分** 之间，批改必须严格对标全国考研英语阅卷组现场细则执行客观从严执裁：

### 1. 按点给分与模拟采分点划分（白纸黑字规则）
- 官方每句满分 2.0 分；
- 根据英文原文、上下文及参考译文（如有），**将每句划分为 3-4 个采分点，分值合计为 2 分，并注明属于模拟划分**；
- **意思准确即可得分，不要求与参考译文用词、语序完全一致**。综合考虑准确性、完整性和中文通顺程度；
- **整句明显扭曲原意，最多得 0.5 分；未作答或译文完全无关，得 0 分**；
- 局部误译、漏译按对应采分点处理，不重复扣分。

### 2. 多选译法与错别字专属判定
- **多选从错原则**：**同一处提供多个备选译法时，若其中有错，按错误译法评价**；
- **错别字累计**：不影响原意的错别字按全篇累计，**每满 3 个扣 0.5 分，不足 3 个不扣**；已按误译扣分的错误不再重复计算，总分最低为 0 分。

### 3. 0.25 分精细微粒度阶梯与错误分类
- **区分真正错误与可选优化**：不把正确但不够漂亮的表达判错；
- **推行 0 / 0.25 / 0.5 三级采分阶梯**：
  - **满分（0.5分/采分点）**：理解准确、关键生词引申恰当、汉语流畅无欧化翻译腔；
  - **部分得分（0.25分/采分点）**：大体意思答出，但存在【语序生硬/被动硬译/漏译限定词/代词未还原/熟词引申欠妥】等瑕疵；
  - **不得分（0分/采分点）**：核心主干颠倒、关键词严重误译、原意完全曲解。

### 4. 欧化“翻译腔”排毒清单
- ❌ **机械硬译被动语态**：把 `be expected to...` 翻成“被期望”，未按汉语习惯转换为主动句或无主句（扣 0.25 分）；
- ❌ **长定语“裹头巾”式硬译**：超过 12 词的长定语从句生硬塞在名词前形成欧化怪长句（扣 0.25~0.5 分）；
- ❌ **代词生硬直译 / 指代模糊**：遇到 `it / they / that` 不结合上文还原实体名词，直接生硬写“它/它们”（扣 0.25 分）；
- ❌ **熟词生义机械代入**：将学术语境核心考点词套用初中日常字典释义（扣 0.25~0.5 分）。
