# 英语一 翻译批改规范（5 个划线长难句，满分 10 分）

## 一、评分规则与核心原则

- **按点给分**：根据英文原文、上下文及参考译文，将每句划分为 3~4 个独立采分点，分值合计为 2 分（注明模拟划分）。意思准确、逻辑清晰即可得分，不苛求与参考译文用词、语序完全一致。
- **基准尺度**：整句明显扭曲原意最多得 0.5 分；未作答或完全无关得 0 分。局部误译/漏译按对应采分点处理，不重复扣分。
- **多译法处理**：同一处提供多个备选译法时，若其中有错，按错误译法评价。
- **错别字累计**：不影响原意的中文错别字按全篇累计，**每满 3 个扣 0.5 分，不足 3 个不扣**；已按误译扣分的错误不重复扣，全卷最低 0 分。
