# 英语一 大作文批改规范（图画作文，满分 20 分）

## 一、评分档位标准（满分 20 分）

- **17—20 分**：很好地完成任务，内容切题，图画象征寓意深刻，要点完整；语法结构和词汇丰富准确，基本无语言错误；衔接自然，层次清晰，论证充分，格式和语域恰当。
- **13—16 分**：较好完成任务，图画理解正确，主要要点完整，允许遗漏少量次要信息；语言较丰富，偶有错误；行文连贯，层次清晰，论证较充分。
- **9—12 分**：基本完成任务，内容基本切题，涵盖多数要点；存在一些语言错误，但不影响整体理解；结构和衔接基本合理。
- **5—8 分**：存在明显审题跑题偏差、图画理解错误、重要要点遗漏或无关内容；语言较单调，错误较多，影响理解；连贯性和论证不足。
- **1—4 分**：未完成任务，明显遗漏主要内容，偏离主题；语言错误严重，缺乏组织与衔接，难以有效传达信息。
- **0 分**：未作答、内容完全无关，或语言过少、原文无法辨认而无法评价。照片模糊时要求重传，不据此判 0 分。

---

## 二、批改原则与核心底线

1. **核对与定档**：先核对题目、图画寓意和写作要求，阅读 `references/checklist-format-wordcount.md` 核对字数（要求 160~200 词，最佳 170~210 词）与段落平衡，结合内容、语言和组织结构综合定档再给分，不机械按错误数量扣分。
2. **两级诊断原则**：严格区分【必须修改】（严重语法错误、拼写搭配硬伤、审题跑题）与【可选优化】（地道词句升级、模板联动）。正确但简单的表达予以保留，绝不扣分。
3. **保留原意与思路**：尽量保留考生的图画立意、论证切入点与正确句式；逻辑不成立或表达不清时才做较大调整并说明原因。
4. **手写识别安全底线**：手写图片必须先完整转录原始文本，保留原有拼写、语法和分段，不得暗中纠错；字迹模糊或有歧义处提请确认，坚决不把 OCR 识别失误当成考生错误。

## 三、本地作文模板与素材词库深度联动

在逐句精批、范文改写与表达提炼中，**必须深度对接本地 `英语/作文模板/` 体系**：
- **核心模板对应**：优先对照 `英语/作文模板/01_27考研最新付费模板（核心主打）/2. 【27考研】图画作文万能模板.pdf` 及 `考研英语作文模板全景指南与速查手册.md`；
- **16 大核心话题素材库**：对于社会公德、青年成长、文化传承、科技创新、人与自然等主流图画话题，优先从 `英语/作文模板/03_大作文高分素材与主题词库/16大核心话题素材库（图画&材料作文）.pdf` 中提取高分论证句与主题词汇升级范文；
- **批改批注指引**：明确标注功能句对应背诵位置（如：“此处第二段深层原因剖析，推荐套用【27考研图画作文模板】论证句 B 结构，替换为您背诵过的……”）。

## 四、输出格式规范（四大核心结构）

① **整体评分与定档**：给出正文词数（排除干扰项）、X/20 分、所属档位，分别从审题切题、语言质量、篇章衔接三维度陈述客观定档依据。  
② **逐句精批**：按“原句 → 问题定位 → 修改句 → 中文解析”呈现，严格标注【必须修改】与【可选优化】。  
③ **修改后全文高分范文**：保留考生正确思路，修正错误与病句，加粗主要修改处，注明词数（170~200 词）。  
④ **复盘积累与闪卡提炼**：提炼 3~5 个考场易复现的高分句式（标注模板出处与适用场景），归纳 3 个最需解决的薄弱点，并同步追加至全局闪卡库。
