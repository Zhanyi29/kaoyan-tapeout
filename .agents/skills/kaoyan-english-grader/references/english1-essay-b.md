# 英语一 大作文批改规范（图画作文，切题性强化版，满分 20 分）

## 一、评分档位标准（满分 20 分）

- **17—20 分**：很好地完成任务，内容切题，图画象征寓意深刻，要点完整；语法结构和词汇丰富准确，基本无语言错误；衔接自然，层次清晰，论证充分，格式和语域恰当。
- **13—16 分**：较好完成任务，图画理解正确，主要要点完整，允许遗漏少量次要信息；语言较丰富，偶有错误；行文连贯，层次清晰，论证较充分。
- **9—12 分**：基本完成任务，内容基本切题，涵盖多数要点；存在一些语言错误，但不影响整体理解；结构和衔接基本合理。
- **5—8 分**：存在明显审题偏差、重要要点遗漏或无关内容；语言较单调，错误较多，影响理解；连贯性和论证不足。
- **1—4 分**：未完成任务，明显遗漏主要内容；语言错误严重，缺乏组织与衔接，难以有效传达信息。
- **0 分**：未作答、内容完全无关，或语言过少、原文无法辨认而无法评价。照片模糊时要求重传，不据此判 0 分。

## 二、切题性强化原则（优先执行，核心权重 50%）

1. **核心寓意精准锁定与图画细节核对**：
   - 先明确图画的关键细节、文字信息、核心寓意与写作任务；
   - 逐段核对作文实际讨论的主题是否与题目一致。**绝对不能仅凭文中出现了题目关键词就轻易判定为切题**。
2. **深度排查“主题偷换”与泛化空论**：
   - 第二段逐一检查论点、解释、例子与图画核心寓意的逻辑链条；
   - **严密识别主题偷换**：例如把“面对失败时的豁达态度”偷换成“个人努力的重要性”、“坚持不懈”等相关但不等同的话题，或者把“养老孝道”泛化为“社会公德”；凡存在主题偷换或外延过度泛化，坚决下调内容完成档位。
3. **万能模板句客观甄别机制**：
   - **区分“合理通用且切题”与“换题目也成立却无实际论证价值”的空泛表述**；
   - 模板本身的框架和连接词**绝不扣分**，只有在模板套话挤占了对图画实质寓意与具体论证的展开时，才影响内容评分。
4. **定档权重法则（切题优先）**：
   - 模拟评分侧重：**切题及任务完成 50%、语言 30%、结构与衔接 20%**（指导综合定档，非机械相加）；
   - **必须先定内容完成档位，再结合语言与结构定分**；严重偏题、偷换概念的作文，**绝不能因为辞藻华丽或从句复杂而进入高分档**。
5. **手写识别安全底线**：
   - 手写图片必须先完整转录原始文本，保留原有拼写、语法和分段，不得暗中纠错；字迹模糊或有歧义处提请确认，坚决不把 OCR 识别失误当成考生错误。

## 三、本地作文模板与素材词库深度联动（骨肉分离法则）

在逐句精批、范文改写与表达提炼中，**必须深度对接本地 `英语/作文模板/` 体系**：
- **核心模板对应**：优先对照 `英语/作文模板/01_27考研最新付费模板（核心主打）/2. 【27考研】图画作文万能模板.pdf` 及 `考研英语作文模板全景指南与速查手册.md`；
- **16 大核心话题素材库**：对于社会公德、青年成长、文化传承、科技创新、人与自然等主流图画话题，优先从 `英语/作文模板/03_大作文高分素材与主题词库/16大核心话题素材库（图画&材料作文）.pdf` 中提取高分论证句与主题词汇升级范文；
- **高分范文生成铁律（紧扣模板 + 本科级地道高分词）**：
  - **骨架极度依托模板**：范文的主干句式、论点引出、过渡连接词必须完全复用考生正在背诵的万能模板句型，帮助考生牢固掌握考场模板框架；
  - **自填部分用词地道不生僻（本科级高分词）**：图画描述中的实体名词、动作细节及象征寓意阐释，**严禁堆砌晦涩生僻词，全面选用大学本科水平、自然地道、符合母语习惯的高分学术词汇**（如用 *convey a profound implication* 替代 *show a deep meaning*，用 *cherish our cultural heritage* 替代 *protect old culture*，用 *indispensable pillar* 替代 *important thing*，用 *foster resilient character* 替代 *make people strong*）；
  - **全文地道度二次闭环审核（Idiomaticity Audit）**：生成范文后，必须全篇自检一遍，确保图画细节与模板套话无缝咬合，杜绝生硬的机器翻译感。

- **逐段吻合度诊断**：
  - 第一段（图画描摹与寓意引出）：高度吻合 / 基本切题 / 细节失真 / 严重偏离
  - 第二段（核心机制与深度论证）：高度切题 / 出现主题泛化 / 存在主题偷换 / 空泛假大空
  - 第三段（对策建议与行动号召）：切题落地 / 过于空洞 / 偏离主题
- **偏题与偷换分析**：<引用考生具体原句，明确指出哪句话最偏离主题、最应在考场上修改，说明为何偷换了概念>

### 二、整体评价与综合评分
- **词数核验**：正文 X 词（标准区间 160~200 词，说明长度是否适中）
- **模拟总分与双评区间**：X 分（考场区间 X ~ X 分） / 满分 20 分
- **所属档位**：<第一档(17-20分) / 第二档(13-16分) / 第三档(9-12分) / 第四档(5-8分) / 第五档(1-4分)>
- **三维定档依据**：
  - 内容与审题（50%）：切题度、论证是否充分、有无假大空
  - 语言准确性与丰富性（30%）：语法准确度、句法多样性、本科级用词地道性
  - 篇章结构与衔接（20%）：三段式布局、过渡逻辑、段落均衡性

### 三、逐句精准精批（行内定位 + 扣分权重）
- 按照 `原句（行内病灶精准标记） → 考场扣分权重【必须修改（考场硬伤扣 0.5~1 分）/ 可选优化（不扣分）】 → 语法/用词规则解析 → 修改后地道句` 逐句呈现。
- 没有明显问题的句子说明可以保留。坚决保护倒装、独立主格、分词等高阶结构，杜绝降智改写。

- 归纳 3 个最需要优先解决的顽疾与专属训练建议。
