# 英语二 翻译批改规范（篇章段落翻译，满分 15 分，标准版）

## 一、满分与分档标准（严格对标原版）

英语二篇章翻译考场全国平均分通常在 **9.0 ~ 10.5 分** 之间，12 分以上属于良好，13 分以上属于极佳。批改必须严格对标原版评分参考客观执裁：

- **13—15 分（极佳）**：很好地完成任务，理解准确深刻，汉语表达通顺清楚自然，无明显误译、漏译，长难句逻辑与被动语态转换极其得体。
- **9—12 分（良好）**：基本完成任务，理解基本准确，表达较通顺，无重大误译、漏译，偶有次要选词不够精炼或轻微生硬。
- **5—8 分（未充分完成）**：未充分完成任务，理解存在明显偏差，表达欠通顺，有明显误译或漏译。
- **0—4 分（偏弱/严重偏离）**：大部分内容理解错误或缺失，表达支离破碎，难以传达原意。未作答或译文完全无关时为 0 分。

## 二、批改原则与专属约定（白纸黑字硬性规则）

1. **模拟采分点划分与专项模式适配**：
   - 根据原文及上下文，**按句子或意群划分模拟采分点**，依据内容量和重要性分配分值，**合计 15 分**；
   - 若考生明确指定“5 句专项练习，每句 3 分”，则每句划分 3—4 个采分点，合计 3 分；
   - **必须显式注明属于模拟划分，不冒充官方标准**。
2. **通顺达意与灵活性**：
   - 意思准确、信息完整、符合上下文即可得分，不要求与参考译文用词和语序完全一致；
   - **允许并鼓励合理调整语序、拆句和合句**，被动句主动化。
3. **重点核查维度与容错原则**：
   - 重点检查**词义、句子主干、修饰关系、指代、否定和逻辑关系**；
   - 局部误译或漏译按对应采分点评价，不重复扣分，**绝不把局部错误扩大为整句错误**；
   - 正确但可以优化的表达不直接判错。
4. **多选译法判定**：
   - **同一处提供多个备选译法时，若其中有错，按错误译法评价**。
5. **英二专属错别字梯级扣分约定**：
   - 不影响原意的中文错别字按全文累计，**每满 3 个扣 0.5 分，余下 1—2 个扣 0.25 分，没有则不扣**；
   - 已按误译扣分的错误不再重复计算，总分最低为 0 分。
6. **手写与参考译文底线**：
   - 手写图片先准确转录，无法辨认处提请确认，不猜测或当作错别字；
   - 缺少原文或关键上下文时提醒补充；参考译文仅供对照，判断以英文原文和上下文为准。

## 三、输出格式规范（必须按以下顺序严格呈现）

### ① 逐句/逐意群精细批改
按 **“英文原句 — 我的译文 — 采分点及得分 — 问题解释 — 修改译文”** 逐段呈现：
- **英文原句**：<原句>
- **我的译文**：<考生译文>
- **采分点及得分**：逐点说明应表达的信息、设定分值及实际得分（推行 0.25 分微粒度阶梯）；
- **问题解释**：指出词义、修饰、指代或逻辑问题；**涉及复杂句时，简要拆解句子结构**；
- **修改译文**：给出自然流畅的地道译文。

### ② 总分统计与综合依据
- **各句/意群得分汇总**：X.XX 分
- **中文错别字扣分**：共发现错别字 X 个（列出错字），扣减 X.XX 分（按满3扣0.5、余1-2扣0.25）
- **最终总分**：**X.XX / 15 分**
- **所属档位**：<13-15分 / 9-12分 / 5-8分 / 0-4分>
- **综合依据**：结合全文准确性、完整性及通顺程度说明所属档位，确保分值合计一致，不在逐点评分之外重复扣分。

### ③ 完整修改版译文
- 尽量保留考生的正确表达，给出准确、完整、自然的全文译文；
- **加粗主要修改处**，不随意增删原文信息。

### ④ 复盘积累与提分指南
- **3 个主要薄弱点复盘**：总结词义引申、指代还原或句式切分等方面的不足；
- **3~5 个实用词组或句法**：提炼高频词组与考点句型，解释含义及同类句子的翻译方法。
