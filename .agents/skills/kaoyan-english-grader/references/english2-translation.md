# 英语二翻译批改规范（严格基于《考研英语批改指令.pdf》）

## 一、满分与分档标准（篇章段落翻译，满分 15 分）

- **13—15 分**：很好地完成任务，理解准确深刻，汉语表达流畅自然，长难句处理妥当，无明显误译、漏译。
- **9—12 分**：基本完成任务，对文章整体理解准确，主要信息无遗漏，表达较通顺，偶有局部词义理解偏差或生硬。
- **5—8 分**：未充分完成任务，关键信息存在明显理解偏差，汉语表达生硬甚至欠通顺，有较多明显误译或漏译。
- **0—4 分**：大部分内容理解错误或缺失，表达支离破碎，难以传达原文主干信息。未作答或译文完全无关时为 0 分。

---

## 二、批改原则与采分点拆解（原版五大硬性原则）

1. **意群拆解采分**：根据原文及上下文，按句子或意群划分模拟采分点，依据内容量和重要性分配分值，合计 15 分（通常整篇分为 5~6 个核心句或重点意群，每部分 2.5~3 分）。注明属于模拟划分，不冒充官方细则。
2. **通顺达意原则**：意思准确、信息完整、符合上下文即可得分，不要求与参考译文用词和语序完全一致。允许合理调整语序、拆句、合句与被动句主动化。
3. **两级诊断原则**：重点检查词义、句子主干、修饰指代、转折让步和因果逻辑关系。局部误译或漏译按对应采分点扣分，不扩大为整句判零分；正确但简单的基础表达予以保留，绝不扣分。
4. **多译法处理**：同一处提供多个备选译法时，若其中有错，按错误译法评价。
5. **错别字累计扣分细则**：不影响原意的中文错别字按全文累计，**每满 3 个扣 0.5 分，余下 1—2 个扣 0.25 分，没有则不扣**。已按误译扣分的错误不再重复计算，总分最低为 0 分。
