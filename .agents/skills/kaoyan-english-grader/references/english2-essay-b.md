# 英语二 大作文批改规范（图表作文，切题性强化版，满分 15 分）

## 一、评分档位标准（满分 15 分，严格对标原版）

- **13—15 分**：内容切题，完整覆盖任务要点，图表描述准确，评论相关且充分；语言丰富准确，行文自然，层次清晰。
- **10—12 分**：较好完成任务，主要要点完整，允许遗漏少量次要信息；语言较丰富，偶有错误，整体连贯。
- **7—9 分（基准档）**：基本完成任务，涵盖多数要点，描述和评论基本合理；语言存在一些错误，但不影响整体理解。
- **4—6 分**：遗漏重要内容或存在理解偏差；语言错误较多，影响理解，组织与衔接不足。
- **1—3 分**：严重偏离任务，遗漏主要内容，语言错误多，难以有效表达意思。
- **0 分**：未作答、内容完全无关，或没有可评价的英文内容。

## 二、切题性强化原则（图表作文特有硬性规则，核心权重 50%）

1. **图表六大要素识别与事实底线**：
   - 重点检查**图表对象、横纵轴、单位、时间（过去时/现状）、数值、比例、排序及变化趋势**；
   - **严格区分静态对比与动态变化**：不把类别差异写成时间趋势；
   - **严禁混淆百分比（percentage）与百分点（percentage points）**，严禁编造数据、篡改年份或误读排序。
2. **第二段原因论证实质咬合机制**：
   - 第二段每一主要分析**必须正面回应图表呈现的现象**；
   - 允许合理推测原因，但**不得将推测写成已被数据证明的事实**；
   - 严厉排查脱离图表泛泛而谈“科技很重要”、“经济高速发展”、“大家都很努力”等放之四海皆准的无关空套话，凡出现此类假大空，直接下调内容完成档位。
3. **对比题目中心现象与作文实际论证主题（排查主题偷换）**：
   - 识别把“新能源汽车销量增长”偷换成“环保意识增强”而忽略产业扶持等多元因素；
   - 识别“只罗列流水账数据而缺少要求的原因评论”或“大段空泛模板挤占数据描述”等病灶。
4. **模拟评分权重法则**：
   - **内容切题及图表任务 50%、语言 30%、组织 20%**；
   - **先定内容完成档位，再结合语言与结构定分**；严重数据失真或偏题的作文，绝不能因词汇华丽进入高分档。
5. **词数与表达客观评判**：
   - 题目要求约 150 词时，不擅自改成必须不少于 150 词，也不编造固定扣分规则；
   - 正确、自然的简单表达予以保留，不以生僻词或连接词数量决定分数，不因使用常见句式直接扣分。

## 三、本地作文模板与素材词库深度联动（骨肉分离法则）

- **模板库对应**：优先对照 `英语/作文模板/01_27考研最新付费模板（核心主打）/1. 【27考研】图表作文万能模板.pdf` 及 `考研英语作文模板全景指南与速查手册.md`；
- **动态 vs 静态精准适配**：
  - 动态图表（折线/柱状趋势）：必须选用动态模板功能句（如 `witness a remarkable surge from ... to ...`）；
  - 静态图表（饼图/柱状占比）：必须选用静态对比功能句（如 `outnumber ... by a wide margin`）；
- **高分范文生成铁律**：
  - **骨架极度依托模板**：牢牢固定在考生熟悉的模板结构上；
  - **自填血肉选用本科地道高分词汇**：严禁堆砌 GRE 冷僻怪词，全面选用大学本科水平的学术图表词汇（如 *account for a lion's share of*, *ascend at an astonishing pace*, *exert a profound influence on*）；
  - **全篇地道度核验（Idiomaticity Audit）**：范文输出前自检一遍，确保图表数据与模板功能句语域统一，加粗主要修改处，不添加无依据的数据或事实。

## 四、输出格式规范（必须按以下顺序严格呈现）

### 一、图表切题核查（切题性强化版核心新增）
- **核心数据与要素核查**：<核验对象、单位、年份、极值、排序是否完全准确无误>
- **主要趋势/对比抓取**：<核查是否准确提炼出首位特征与主要反差，而非流水账报数>
- **评论与图表相关性**：<核查第二段原因分析是否紧扣图表核心驱动力，有无假大空套话>
- **逐段离题句定位**：<逐段列出明显离题或无意义凑字数的句子，说明修改建议>

### 二、整体评价与综合评分
- **词数核验**：正文 X 词（符合考场约 150 词标准，安全区间 140~180 词）
- **模拟总分与双评区间**：X 分（考场区间 X ~ X 分） / 满分 15 分
- **所属档位**：<第一档(13-15分) / 第二档(10-12分) / 第三档(7-9分) / 第四档(4-6分) / 第五档(1-3分)>
- **具体依据**：分别从内容与图表切题（50%）、语言准确度（30%）、篇章结构（20%）阐述依据。

### 三、逐句精准精批（行内定位 + 扣分权重）
- 按照 `原句（行内病灶精准标记） → 考场扣分权重【必须修改 / 可选优化】 → 语法/数据趋势规则解析 → 修改后地道句` 逐句呈现。
- **特别指出数据和趋势表达问题**（如混淆 percentage 与 percentage points、类别差异误用时间趋势词等）。

### 四、修改后全文高分范文
- 骨架依托图表万能模板，自填血肉采用本科地道高分词，不添加无依据事实，加粗主要修改处；
- 注明修改后词数与【全篇地道性核验结论】。

### 五、范文逐句中英精讲与模板实战教学
对高分范文逐句精讲：
1. **【范文原句 & 地道中文翻译】**；
2. **【骨肉分离拆解】**：标明【图表模板骨架】与【自填图表数据/原因血肉】；
3. **【高分词汇/短语剖析】**：对比普通图表词，说明为何高级地道；
4. **【模板实战教法与举一反三】**：说明如何一键迁移套用到同类动态/静态图表考题。

### 六、考场高频推荐表达积累（与模板联动）
- 提炼 3~5 个考场易复现的高分图表词组或句式，解释含义、用法与模板对应位置。

### 七、写作思路与复盘
- 总结本题图表写作思路与可替换框架；
- 归纳 3 个最需要优先改进的问题与专项练习建议。
