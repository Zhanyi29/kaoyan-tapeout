# 英语二 小作文批改规范（应用文，切题性强化版，满分 10 分）

## 一、评分档位标准（满分 10 分，严格对标原版）

- **8—9 分（基准最高档）**：很好地完成任务，要点完整，语言准确自然，表达有变化，行文连贯，格式和语气恰当。**各方面表现充分、无明显不足时可给 10 分，不人为封顶**。
- **6—7 分**：较好完成任务，主要要点完整，允许遗漏少量次要信息；语言基本准确，偶有错误，组织清晰，格式和语气适当。
- **4—5 分**：基本完成任务，涵盖多数要点；有一些语言错误，但不影响整体理解，结构和格式基本合理。
- **2—3 分**：遗漏重要要点或夹杂无关内容；语言错误较多，影响理解，衔接不足，格式或语气不当。
- **1 分**：未完成任务，明显遗漏主要内容，语言错误严重，难以有效传达信息。
- **0 分**：未作答、内容完全无关，或没有可评价的英文内容。

## 二、切题性强化原则（原版硬性规则，核心权重 50%）

1. **切题与任务要点核查前置输出**：
   - 先对照题干核查**身份、写作对象、写信目的、必答要点与回复动作**；
   - 按照【完整】/【部分】/【缺失】逐项列出清单，**作为综合定档的核心首要依据**。
2. **交际任务为主，严防套话挤占**：
   - 审核正文是否以完成具体交际任务为主；
   - **绝不能以空泛套话、客套祝愿、复杂从句替代具体的实质说明**；对遗漏的实质信息优先修改。
3. **人际语气得体，不搞一刀切正式化**：
   - 语气评价必须符合双方真实关系：写给教授/学术机构采用正式、礼貌、委婉的语气；写给留学生/朋友/同辈采用半正式、友好客气的语气；**不强制把所有文章都改造成死板生硬的正式公文**。
4. **模拟评分权重法则**：
   - **内容与任务 50%、语言 30%、结构格式 20%**；
   - **主要任务缺失时，绝不能因语言准确或高级而给高分**。
5. **词数说明与语法例句刚性要求**：
   - 统计正文词数（标准约为 100 词，建议 80~120 词），称呼、结束语和署名单独说明；
   - **涉及语法错误时，简要解释规则，且必须给出一个清晰例句**（杜绝空洞说教）。

## 三、本地小作文模板库深度联动（背诵与实战结合）

- **模板库对应**：优先对照 `英语/作文模板/02_小作文全套合集（书信·告示·纪要）/` 下的各类书信范文与导图；
- **骨架依托与血肉填充**：
  - 骨架复用模板中地道规范的交际功能句；
  - 自填血肉采用得体易记的本科级书信词汇；
- **全篇地道性与语域核验**：确保格式（称呼标点、缩进/空行、署名分写）、语域、语气整体协调一致。

- **发信人身份与写作对象**：<题干规定身份及收信人关系>
- **核心交际目的**：<祝贺/建议/介绍/道歉/感谢/倡议等>
- **必答要点与回复动作核查表**：
  - 要点 1：<要点内容> ➔ 【完整 / 部分 / 缺失】（简要说明原因）
  - 要点 2：<要点内容> ➔ 【完整 / 部分 / 缺失】（简要说明原因）
  - 要点 3：<要点内容> ➔ 【完整 / 部分 / 缺失】（简要说明原因）

### 二、整体评分与定档依据
- **词数统计说明**：正文 X 词（称呼与署名另计，长度评价）
- **模拟总分与双评区间**：X 分（考场区间 X ~ X 分） / 满分 10 分
- **所属档位**：<优秀档(8-10分) / 良好档(6-7分) / 及格档(4-5分) / 偏弱档(2-3分) / 低分档(0-1分)>
- **具体依据**：分别从任务完成度（50%）、语言质量（30%）、格式与语气（20%）阐述定档依据。

### 三、逐句精准精批（行内定位 + 扣分权重）
- 按照 `原句（行内病灶精准标记） → 考场扣分权重【必须修改 / 可选优化】 → 规则解释与修正例句 → 修改后地道句` 逐句呈现。
- **涉及语法错误时，必须给出一个正误对比或造句例句**。

### 四、修改后全文高分范文
- 骨架依托小作文模板库，优先补全遗漏的实质要点，加粗主要修改处；
- 注明修改后词数与语域得体性核查结论。

### 五、范文逐句中英精讲与模板实战教学
对高分范文逐句精讲：
1. **【范文原句 & 地道中文翻译】**；
2. **【骨肉分离拆解】**：清晰标明【模板骨架礼貌句】与【针对任务填入的交际血肉】；
3. **【高分交际用词剖析】**：剖析得体委婉的用词亮点；
4. **【模板实战教法与举一反三】**：说明如何一键迁移到同类应用文题型。

- 提炼 3~5 个高频实用书信表达，注明中文含义、用法与适用场景。

### 七、复盘积累与针对性改进点
