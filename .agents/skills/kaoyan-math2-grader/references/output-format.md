# 输出格式（逐题批改、大题总分统计与单题精批）

## 一、每道大题的输出格式（整卷批改场景）

对整卷批改中的每一道解答题，严格按以下结构输出：

---

# 【第X题】

## 1. 考查知识点

说明本题主要考查的数学二知识点。

## 2. 标准解题思路

简要说明正确的解题逻辑，重点说明：如何切入、关键方法、关键公式、最终如何得到答案。不要过度重复完整标准答案。

## 3. 我的解题过程分析

按照用户实际书写过程逐步分析：

### 第一步

- 我的做法：
- 正确性判断：
- 分析：
- 得分情况：

### 第二步

- 我的做法：
- 正确性判断：
- 分析：
- 得分情况：

（按实际步骤数量依次展开）

## 4. 得分点分析

使用表格：

| 得分点 | 分值 | 我的表现 | 判定 | 得分 |
|---|---:|---|---|---:|
| 得分点1 | X | …… | 正确/部分正确/错误 | X |
| 得分点2 | X | …… | 正确/部分正确/错误 | X |
| 得分点3 | X | …… | 正确/部分正确/错误 | X |

（若没有明确的逐步评分标准，在表格前声明：「以下得分点拆分为基于考研数学主观题阅卷逻辑的合理估计，并非官方明确评分细则。」）

## 5. 错误定位

### 错误1

- 错误位置：
- 错误类型：（按 grading-rules.md 的 A–F 分类标注）
- 具体问题：
- 正确做法：
- 对后续的影响：
- 扣分情况：

（多个错误依次编号为 错误1 / 错误2 / ……。如果没有明显错误，明确写出：**本题未发现实质性错误。**）

## 6. 最终评分

**本题得分：X / X分**（说明得分依据）

---

## 二、大题总分统计（整卷批改场景）

所有大题批改完成后，统计：

| 解答题 | 满分 | 我的得分 | 失分 |
|---|---:|---:|---:|
| 第X题 | X | X | X |
| 第X题 | X | X | X |
| 第X题 | X | X | X |

# 解答题总成绩

**X / 解答题总分**

# 解答题得分率

**X%**

注意：
- 不要计算整套数学二试卷的 150 分总分，本次只统计【解答题部分】。
- 选择题、填空题不出现在任何评分、分析与统计中。

---
