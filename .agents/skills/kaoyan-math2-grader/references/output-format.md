# 输出格式（逐题批改、大题总分统计与单题精批）

## 一、每道大题的输出格式（整卷批改场景）

对整卷批改中的每一道解答题，严格按以下结构输出：

---

# 【第X题】

## 1. 考查知识点

说明本题主要考查的数学二知识点。

## 2. 标准解题思路

简要说明正确的解题逻辑，重点说明：如何切入、关键方法、关键公式、最终如何得到答案。不要过度重复完整标准答案。

## 3. 我的解题过程深度展开与关键答案核验（防识别误差）

### (1) 考生关键中间答案与最终结果提取（供考生比对防误判）

> 💡 **防识别错误核验说明**：为防止 OCR 识图误差、笔迹潦草或看错数字导致误判，请先核验以下从答题卡提取出的关键结果是否与你的真实作答一致：

| 关键采分阶段 | AI 识别到的考生计算结果 / 表达式 | 标准参考结果 | 判定状态 |
| :--- | :--- | :--- | :--- |
| **关键中间答案 1**（如：特征多项式/驻点/导函数） | `$考生实际所写公式或数值$` | `$标准公式或数值$` | 一致 / 偏差（见后文分析） / 【字迹存疑】 |
| **关键中间答案 2**（如：通解/特解/极值/积分结果） | `$考生实际所写公式或数值$` | `$标准公式或数值$` | 一致 / 偏差 / 【字迹存疑】 |
| **最终答案 / 结论** | `$考生最终得出的答案$` | `$标准最终答案$` | 一致 / 错误 / 【字迹存疑】 |

*(注：若考生发现上述关键答案与答题卡实际书写不符，请直接指出，将立即以考生实际书写为准重判)*

### (2) 解题过程逐层展开深度诊断

（严禁概括性泛泛而谈，必须还原考生真实演算轨迹，逐段展开数学逻辑与算理剖析）

#### 步骤一：<阶段名称，例如：建立方程 / 换元转化 / 特征值求解>
- **考生原式与具体推导**：<完整摘录考生此处实际写下的数学表达式、变形过程与代入值>
- **算理与数学逻辑深度分析**：<深入剖析此处逻辑链条：公式是否用对、定理前提条件是否验证、变形是否同解、逻辑是否自洽>
- **关键计算与正误判定**：【正确 / 存在逻辑漏洞 / 计算失误】
- **本阶段给分**：得分：X 分（依据：……）

#### 步骤二：<阶段名称，例如：关键积分计算 / 特解推导 / 矩阵初等变换>
- **考生原式与具体推导**：<完整摘录考生此处实际写下的数学表达式、变形过程与代入值>
- **算理与数学逻辑深度分析**：<若此处出错，必须精确定位是哪一步符号算错、哪一步积分漏项、或是方法不适用；若正确，评价其推导严密性>
- **关键计算与正误判定**：【正确 / 存在逻辑漏洞 / 计算失误】
- **本阶段给分**：得分：X 分（依据：……）

（依据考生实际书写的阶段数量依次完整展开，不可省略跳步）
