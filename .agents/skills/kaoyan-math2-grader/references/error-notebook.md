# 错题集整理与归档规范（批改与复盘后必读）

## 一、整理目标与时机

每套考研数学二试卷批改和整卷复盘输出完成后，**必须自动执行错题归档**：
将本套试卷中所有产生失分的题目（包含解答题扣分题，以及用户在对话中提及或答卷中呈现的选择题、填空题错题），整理为一个独立的 Markdown 文件，存放在工作区根目录的 `错题/` 文件夹下。

- **目标存储路径与命名规范（强制包含完成日期）**：
  - **历年真题**：`错题/真题/<试卷年份与名称>_<完成日期>.md`（例如：`错题/真题/2023年考研数学二真题_2026-09-23.md`）
  - **名师模拟卷（细分名师与卷种）**：`错题/模拟卷/<名师名称>/<卷种简称>/<试卷名称>_<完成日期>.md`（例如：`错题/模拟卷/张宇/27张八/2027张宇八套卷_卷一_2026-09-20.md`，或 `错题/模拟卷/李林/27李六/2027李林六套卷_卷一_2026-10-15.md` 等）
  - **阶段复习与汇总卷**：`错题/阶段复习/<复习主题与阶段>_<完成日期>.md`（参见 `references/stage-review.md`）
- **命名铁律**：文件名中**必须保留清晰试卷名与完成日期**（如 `_YYYY-MM-DD.md`），严禁省略日期，文件内开头一级标题与元数据中的整理日期保持一致。

---

## 二、核心排版铁律（最高优先级）

> [!IMPORTANT]
> **「题目集中在前」与「答案集中在后」彻底分离，严禁“一题一解”穿插排版！**
> 
> - **前半部分（题目汇总篇）**：所有错题的完整题干必须集中放在一起，**绝对不能**在题目下方紧跟答案、解析或错因提示。其目的是作为一份纯净的“重做卷”，方便用户闭卷二次练习、打印或在草稿纸上重做。
> - **后半部分（答案解析篇）**：所有错题的官方标准答案、详细推导、给分步骤、考场错因深度诊断与考点提炼集中放在后面。

## 四、执行要点

1. **官方解法优先**：答案与解析必须严格以官方解析为主，**优先取自工作区本地解析 PDF**（`数学二答案解析分年/`、`模拟卷/` 下各卷解析）；本地没有该卷解析时，再依据用户提供的材料或可靠公开资料，并注明来源。确保步骤严谨、采分点明确。
2. **错题覆盖全面**：不仅包含解答题失分题目，如果用户在对话中提到做错的选择题、填空题（例如“填空第12题错了”、“选择第10题是错题”），必须主动纳入统计与整理。
3. **完成后即时汇报**：文件写入完毕后，在向用户汇报的对话中提供指向该文件的可点击链接，并简要概括错题结构。
