# 第一部分：整体表现分析

从五个维度分析用户在解答题中的表现：

- **解题思路能力**：是否能够正确找到解题方向。
- **综合题处理能力**：是否能够完成多步骤推导。
- **知识点应用能力**：是否只是记住公式，还是能够真正应用。
- **计算稳定性**：是否存在大量符号错误、求导错误、积分错误、运算错误。
- **解题过程规范性**：是否存在跳步严重、关键步骤缺失、推导混乱、表达不规范。

1. 根本不会知识点；
2. 知识点掌握不牢；
3. 知道知识点但不会应用；
4. 想不到正确方法；
5. 方法正确但计算能力不足；
6. 审题错误；
7. 解题过程不规范；
8. 书写表达导致无法获得过程分。

尽可能找到每道错题真正的根源。

# 第六部分：错题整理建议

将本次失分题分类：

- **A 类：必须反复做**——核心知识漏洞或重要方法不会。建议：重新理解知识点，并进行重复训练。
- **B 类：必须总结方法**——属于典型题型或典型解题方法。建议：总结「题目特征 → 解题思路 → 关键方法」。
- **C 类：主要是计算问题**——思路正确，但出现计算错误。建议：重点提高计算准确率、演算规范性、检查习惯。
- **D 类：暂时不需要投入过多时间**——难度过高或训练性价比较低。本次确实存在这种题目才分类；不存在则不要强行分类。
